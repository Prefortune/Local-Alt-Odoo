bizzup_inventory_customization
=======================

This module will restrict Inevntory/User group, to Create Tansfer which are not Internal Tranfer
But These users can create Internal Transfer From  SO, PO, POS and Repair.

Configuration
=============
* Please Provide Uer Group to current Logged in user To 'Inventory'.
* In User From View -> In Extra Right Section -> There is one access named 'Allow Inventory Adjustment?'
  - If The Access is False, Current Logged in user can not click on 'Apply all' button in Inventory Adjustment report.
  - But User can edit Counted Qty
  - User can not click the apply button through the Stock count in the barcode
  - User also can not print the reports: Count sheet
