About
============
This module allows you to create a quotation/sale order from the point of sale. Sometimes while using POS we need to make the quotation/sale order for that customer then you have to go back and create a quotation/sale order. So we have added a quick button to create quotation/sale order directly from the POS screen.

Installation
============
1) Copy module files to addon folder.
2) Restart odoo service (sudo service odoo-server restart).
3) Go to your odoo instance and open apps (make sure to activate debug mode).
4) click on update app list.
5) search module name and hit install button.
