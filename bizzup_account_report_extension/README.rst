Bizzup Account Report Extension
===============================

Custom extension for Partner Ledger and Account Move Line reporting in Bizzup.

Key Features
------------
* Enhances Partner Ledger reports.
* Extends Account Move Line reporting capabilities.
* Tailored to Bizzup's accounting workflows.

Configuration
=============
* No additional configuration is required.
