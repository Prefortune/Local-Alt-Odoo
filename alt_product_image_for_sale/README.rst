======================
Alt Product Image for Sale
======================

This module adds product images to sale orders, quotations, and their reports in Odoo 18.

Features
--------

* Display product images in sale orders and quotations
* Choose from three image sizes: Big, Medium, and Small
* Include product images in quotation and sale reports
* Toggle image display in reports with a simple checkbox
* Hide price summary table in quotations (not applicable for confirmed orders)
* Fully compatible with Odoo 18 Enterprise

Installation
-----------

1. Install the module
2. Go to Sales > Configuration > Settings
3. Enable the "Product Images" feature
4. Restart your Odoo server

Usage
-----

1. Create or edit a sale order
2. Check the "Print Image" option
3. Select your preferred image size
4. Optionally check "Hide Summary in Quote" to hide price summary in quotations
5. Save and print your document

New Feature: Hide Summary in Quote
---------------------------------

* When the checkbox is checked, quotations will be sent without the price summary table
* This feature only applies to quotations (draft state), not confirmed orders
* Useful for sending initial quotes without revealing detailed pricing breakdown
