Streamline Your Odoo Inventory with the Product Image Import Feature

After installing the module, a new "Product Image Import" function will be available in the Inventory module. To use this feature, go to Inventory → Configuration → Product Image Import → Import Images. This will allow you to upload a ZIP file containing images for your products.

Effortlessly Upload Product Images with the Import Images Wizard

By clicking on the "Import Images" option, a wizard will open where you can upload a ZIP file and define a file name. This wizard streamlines the process of importing multiple product images at once, allowing you to efficiently manage and update your product catalog.

Viewing Matched and Unmatched Product Images After Importing in Odoo

When we import the ZIP file, the images that have been successfully matched will appear in the updated product fields, while unmatched images will be listed under the unmatched filenames fields. Unmatched files indicate that the image did not match the product's display name, internal reference, or barcode in Odoo. The unmatched filenames fields allow you to easily identify which product images were not updated in Odoo.

What image formats are supported by the Bulk Product Image Import feature?

The feature supports .png, .jpg, and .jpeg file formats.

How does the module match images to products?

The module matches images to products based on the display name, barcode, or internal reference specified in Odoo. You can configure the matching criteria according to your needs.

What happens if an image in the ZIP file doesn't match any product?

Images that do not match any product will be listed under "Unmatched Filenames." You can review these files to identify which product images were not updated.

Can I import images for multiple products at once?

Yes, you can import images for multiple products at once by uploading a ZIP file containing all the images. The module will automatically distribute the images to the correct products.

Where do I find the option to import product images in Odoo?

You can find the option by navigating to Inventory → Configuration → Product Image Import → Import Images.

What should I do if an image doesn't update for a product?

If an image doesn't update, check the "Unmatched Filenames" field to see if the file name didn't match the product's display name, barcode, or internal reference. You may need to adjust the file name or criteria and try again.

Is there a limit to the number of images I can import at once?

The module is designed to handle bulk imports, so you can import a large number of images at once. However, the exact limit may depend on your Odoo installation and server capacity.

Can I re-import images if I make a mistake?

Yes, you can re-import images by uploading a new ZIP file. The module will update the existing images based on the matching criteria.

What if I want to use a different identifier for matching images, such as a custom field?

The module can be customized to match images based on a custom field if needed. This may require additional development or configuration depending on your specific requirements.
