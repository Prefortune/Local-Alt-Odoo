# Alt Split Delivery Module for Odoo 18

מודול משלוחים מפוצלים מתקדם לאודו 18

## תיאור

מודול זה מוסיף שיטת משלוח מתקדמת לאודו 18 המאפשרת ללקוחות לרכוש מספר משלוחים עבור הזמנה אחת ולנהל אותם דרך פורטל הלקוח. המודול תומך בעברית ומתאים במיוחד לחברות שצריכות לשלוח מוצרים לכתובות שונות מאותה הזמנה.

## תכונות עיקריות

- **משלוחים מרובים**: אפשרות לרכוש מספר משלוחים עבור הזמנה אחת
- **ניהול כתובות**: הגדרת כתובות שונות לכל משלוח דרך פורטל הלקוח
- **תאריכי משלוח**: אפשרות לקבוע תאריך משלוח רצוי
- **כרטיס ברכה**: הוספת הודעה אישית למשלוח
- **הערות משלוח**: הוספת הוראות מיוחדות למשלוח
- **מעקב מלא**: מעקב אחר כל משלוח בנפרד דרך מערכת המלאי
- **תמיכה בעברית**: ממשק משתמש מלא בעברית
- **אינטגרציה מלאה**: אינטגרציה עם מערכות המשלוחים והמלאי של אודו

## התקנה

1. העתק את המודול לתיקיית `addons` של אודו
2. עדכן את רשימת המודולים באודו
3. התקן את המודול "Alt Split Deliveries"
4. הפעל את המודול
5. הגדר ספקי משלוח לתמיכה במשלוחים מפוצלים

## שימוש

### הגדרת ספק משלוח

1. עבור להגדרות > משלוחים > ספקי משלוח
2. בחר ספק משלוח
3. הפעל "Supports Split Delivery"
4. שמור

### תהליך הזמנה

1. **באתר**: הלקוח בוחר מספר משלוחים במהלך התשלום
2. **אחרי התשלום**: הלקוח מועבר לפורטל לניהול כתובות המשלוח
3. **ניהול משלוחים**: הלקוח יכול להגדיר כתובות שונות לכל משלוח
4. **מעקב**: מעקב אחר כל משלוח בנפרד

### ניהול משלוחים

- עבור לתפריט "מכירות > הגדרות > משלוחים מפוצלים"
- צפה בכל המשלוחים המפוצלים
- עדכן סטטוס משלוחים
- עקוב אחר משלוחים בדרך

## דרישות מערכת

- **Odoo 18.0 Community**
- מודול מכירות (sale)
- מודול מלאי (stock)
- מודול משלוחים (delivery)
- מודול אתר מכירות (website_sale)

## תכונות מתקדמות

### ניהול תאריכים
- הלקוח יכול לקבוע תאריך משלוח רצוי
- תאריכים זמינים החל מ-10 ימי עסקים לאחר אישור ההזמנה

### כרטיס ברכה והערות
- הוספת הודעה אישית לכל משלוח
- הערות מיוחדות להוראות משלוח

### אינטגרציה עם מלאי
- יצירת תנועות מלאי נפרדות לכל משלוח
- מעקב אחר מצב כל משלוח בנפרד
- ניהול כתובות משלוח דרך שותפים

### אבטחה
- גישה מוגבלת לבעלי הזמנות בלבד
- הרשאות מנהל למנהלי מכירות
