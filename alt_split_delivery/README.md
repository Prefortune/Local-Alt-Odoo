# Split Deliveries Module for Odoo 18

מודול משלוחים מפוצלים לאודו 18

## תיאור

מודול זה מוסיף שיטת משלוח חדשה לאודו 18 המאפשרת לפצל הזמנה אחת למספר כתובות משלוח שונות. המודול תומך בעברית ומתאים במיוחד לחברות שצריכות לשלוח מוצרים לכתובות שונות מאותה הזמנה.

## תכונות עיקריות

- **משלוחים מפוצלים**: אפשרות ליצור מספר משלוחים מאותה הזמנה
- **כתובות משלוח מרובות**: כל משלוח יכול להיות לכתובת שונה
- **מעקב סטטוס**: מעקב אחר סטטוס כל משלוח בנפרד
- **תמיכה בעברית**: ממשק משתמש מלא בעברית
- **אינטגרציה עם הזמנות**: אינטגרציה מלאה עם מודול הזמנות המכירה

## התקנה

1. העתק את המודול לתיקיית `addons` של אודו
2. עדכן את רשימת המודולים באודו
3. התקן את המודול "Split Deliveries"
4. הפעל את המודול

## שימוש

### יצירת משלוח מפוצל

1. עבור להזמנת מכירה
2. לחץ על "צור משלוח מפוצל"
3. מלא את פרטי כתובת המשלוח
4. בחר את הפריטים למשלוח
5. שמור את המשלוח

### מעקב אחר משלוחים

- עבור לתפריט "מכירות > הגדרות > משלוחים מפוצלים"
- צפה בכל המשלוחים המפוצלים
- עדכן סטטוס משלוחים
- עקוב אחר משלוחים בדרך

## מבנה המודול

```
alt_split_delivery/
├── __manifest__.py          # הגדרות המודול
├── models/
│   ├── __init__.py
│   ├── split_delivery.py    # מודל המשלוחים המפוצלים
│   └── sale_order.py        # הרחבה להזמנות מכירה
├── views/
│   ├── split_delivery_views.xml    # תצוגות משלוחים מפוצלים
│   └── sale_order_views.xml        # תצוגות מורחבות להזמנות
├── security/
│   └── ir.model.access.csv         # הרשאות
└── data/
    └── split_delivery_data.xml     # נתונים ראשוניים
```
