Detailed Features

01 Facebook Lead Sync - Pull leads from Facebook Lead Ads as soon as users submit forms. Supports multiple forms and pages.
02 Direct CRM Integration - Each Facebook lead submission is automatically turned into a new lead/opportunity in Odoo CRM. All essential contact details are saved directly to the CRM record.
03 Simple Facebook Page & Form Setup - Easily connect your Facebook page and associated lead forms using access tokens or secure API integration.
04 Custom Field Mapping - Map Facebook form fields (like name, phone, email, product interest) to any custom fields in your Odoo CRM.
05 Track Campaign Sources - Tag leads with campaign/form info for better tracking and segmentation. Easily view and filter leads by campaign source within your CRM dashboard.

Set Up

To begin with, have the CRM Facebook Lead Integration - Facebook Leads Connector Module downloaded on your system. For its proper setup, go through the steps below.

Firstly, you need to install the CRM Facebook Lead Integration - Facebook Leads Connector App from Odoo Apps. It's easy to locate, just search for the name, you can identify it with the change radio button icon. Ta-da, you are ready to go!!

Work Flow

To grant a user access to the CRM Facebook Lead Integration - Facebook Leads Connector functionality go to Settings → Users & Companies → Users. Select the user, then tick the Facebook Leads Access option.
The Facebook Leads menu will now be visible. To fetch leads from Facebook, you need the Facebook App ID and App Secret Token. To add these credentials, go to Facebook Leads → Facebook App Credential, then click the New button to add a new Facebook App Credential record. Now insert the Facebook App ID and secret token.
Now, click the Generate Token button. This will redirect you to Facebook, where you need to log in and grant access to the pages from which you want to fetch leads into Odoo.
After the process is completed, the Page Access Token will be retrieved and automatically set in the User Access Token field of the current record.

To retrieve the Facebook pages, click the Fetch Facebook Pages button. This will fetch all Facebook pages associated with the connected account.
You can see all the Facebook pages linked to this app. Click the smart button labeled Facebook Pages to view them.
Now, click on the particular page, and you will see the page information of the related account.
Click the Fetch Forms button to fetch all forms related to this page. You can view them under the Lead Forms tab inside the page.
Now, click on a View button in specific form to view its details and other configuration settings related to it.

If you want to map additional fields from your form, you just need the Facebook form field name. Then, select the corresponding Odoo field from the dropdown to bind it. Once mapped, the data from Facebook will automatically be displayed in the selected Odoo field.
To fetch the leads for a specific form, click the Fetch Leads button. This will retrieve all leads associated with that particular form.
Now, click the Leads smart button to view the lead information along with the fields mapped to Odoo CRM. By default, the lead will be in the New stage.
