Event sponsorship in Odoo

The Event Sponsorship module allows users to add sponsorship details to each event, which are then displayed on the event page for potential sponsors to view. When a sponsor clicks the "Apply" button, they are redirected to a Stripe Checkout page to complete their payment securely. After successful payment, a confirmation screen is shown, and email notifications are automatically sent both to the sponsor and the responsible event organizer. To use this feature, Stripe credentials must be configured under the General Settings.

Complete Workflow for Event sponsorship in odoo

Configure Event Settings – Go to Event Settings and enter the Stripe Secret Key.Next, add sponsorship details to each event. When a sponsor decides to apply, they can click the "Apply" button, which redirects them to Stripe's secure Checkout page to complete the payment. Once the payment is successfully processed, a confirmation screen is displayed. Finally, automated email notifications are sent to both the sponsor and the event organizer, confirming the sponsorship and payment details.

Note :This module uses the Stripe Payment Gateway for processing sponsorship payments. Therefore, the Python library (stripe) is required for proper functionality.


Event sponsorship

1. Install Event Sponsorship module

2. Go to Event Settings and enter the Stripe Secret Key.

3. Go to the Event menu, create a new event, and enable the 'Active Sponsorship' field. Than show the two sections will appear: 'Sponsorship' and 'Sponsorship Apply.

4. In the 'Sponsorship' section, add the sponsorship details, and then click the 'Go to Website' button

5. Show the Event Sponsorship on the website And click on the 'Apply' button make a payment..

6. Fill in all the details and click the 'Payment' button.

8. Go to the Event menu and view the 'Sponsorship Apply' section, where the sponsership details are displayed once the payment is completed.

9. Click on the information icon to view the details of the particular event.

10. Once the payment is successfully processed, an automated email notification is sent.
