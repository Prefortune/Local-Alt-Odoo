Bizzup Stock Customization
=======================
*This module helps manage the consignment transfer in an inter-company system.*

## Configuration

- For a **consignment sale order**, set the **SO Consign** boolean to `True` and specify the **Consign Location** in the partner or enable the **Is Consignation Location** boolean in the stock location.
- To **create an invoice and picking in the main company** when validating the picking in a subsidiary company, enable the **Is Consign Transfer** boolean in inventory settings.
- Update the domain of the **'Account Entry' record rule** to `[(1, '=', 1)]`.
